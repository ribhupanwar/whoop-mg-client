## State rules

- **IMPLEMENTED** = concrete code exists, meaningful validation is still pending unless separately stated.
- **ALREADY PRESENT** = verified in existing source; not a clinical/device success claim.
- **TESTED** = named deterministic tests or explicit device evidence passed; scope/limitations remain in the evidence column.
- **DEVICE VALIDATION PENDING** = code/tests cannot establish physical sensor, signing, accuracy, background or battery behavior.
- **BLOCKED** = an explicit implementation gap or missing external input, identified in the evidence/next-action text. Implementation gaps are queued, not declared impossible.
- **NOT FEASIBLE** = cannot honestly produce the requested claim from available inputs/source. Never substitute fabricated readings.

No item is marked complete merely because it compiles. Multiple labels capture different dimensions of the same item.
