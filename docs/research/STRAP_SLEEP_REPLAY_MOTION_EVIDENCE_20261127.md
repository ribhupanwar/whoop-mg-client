# Sleep replay and observed motion
Based on main f36fa618. Current sleep detector already applies coarse band state, HR drop, motion, onset/wake and bathroom-resumption guards. Two local defects: duplicate seconds could inflate counts and missing motion was counted as a waking disturbance and as active HR reference. Reuse existing whole-record history preference and distinguish measured movement from absent/invalid motion. Python mirror and synthetic fixtures included; no new threshold or firmware command. This is not validated V21-to-sleep fusion or guaranteed WHOOP parity. New IMU features in #318 require aligned captured blocks and independent sleep evidence before changing the classifier. Native and Python CI required.
